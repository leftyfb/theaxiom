## Operation

The existing Internet Archive source is preconfigured, not downloaded or published by installation. An operator selects it and initiates the generic PDF acquisition, digest verification and publication workflow. The local PDF.js reader handles page images and offline navigation. The shared PDF/EPUB search supports catalog title, author, subject description and extractable page/chapter text. Search and reader access are gated on verified publication; no live Internet Archive request is required for reading or searching.

There is no regular new-edition schedule for this fixed 1911 book. The same configured direct URL is available for conservative document HEAD checks using the normal notify policy. Internet Archive may redirect downloads, so a comparable strong ETag is not guaranteed; the checker may report an inconclusive status rather than assume a new edition. The exact pin prevents silent substitution. Revalidate rights, size and digests before approving a replacement. There is no Internet Archive-specific downloader, automatic bulk mirror, or collection-level search adapter.

The existing packaged local source icon is reused. Additional independently licensed items may be added through the normal PDF/EPUB source form rather than a new provider-specific adapter.
